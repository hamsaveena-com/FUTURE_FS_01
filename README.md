# Movie Ticket Booking System

A web-based movie ticket booking system built using HTML, CSS, JavaScript, Node.js, Express, and PostgreSQL (Supabase).

## Features

- Movie selection
- Seat selection
- Booking system
- Booked-seat tracking
- PostgreSQL database
- Backend API using Node.js and Express

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Supabase
