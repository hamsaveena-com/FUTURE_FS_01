# 🎬 Movie Ticket Booking System

A web-based **Movie Ticket Booking System** that allows users to select movies, choose seats, and book tickets through a simple and user-friendly interface.

## 🚀 Features

* 🎥 Movie selection
* 💺 Seat selection
* 🎟️ Ticket booking
* 🔒 Booked-seat tracking
* 💰 Automatic ticket price calculation
* 🗄️ PostgreSQL database
* ⚙️ REST API using Node.js and Express
* 🌐 Responsive and user-friendly interface

## 🛠️ Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* PostgreSQL
* Supabase

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/hamsaveena-com/FUTURE_FS_01.git
```

### 2. Start the backend

```bash
cd backend
npm install
node server.js
```

The backend will run on:

```text
http://localhost:5000
```

### 3. Run the frontend

Open the `frontend/index.html` file using **Live Server** in VS Code.
